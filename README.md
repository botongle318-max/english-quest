# 🗺️ English Quest · 英语口语闯关大冒险

一个**卡通闯关式**的英语学习网站：和卡通角色进行实景对话、击败词汇 BOSS、攒星星升级，**手机和电脑浏览器都能直接玩**，无需安装、无需注册、无需后端服务器。

面向大学生及成人英语学习者，重点练习**日常口语对话**与**核心词汇**。

## 🎮 玩法

- **6 大主题世界、24 个关卡**：咖啡馆餐厅、旅行交通、酒店住宿、日常生活、职场商务、社交日常
- **对话闯关**：每关 5 轮实景多轮对话，从 3 个回复中选出最地道的表达；选错会扣 ❤️ 并得到讲解提示
- **BOSS 词汇战**：每个世界最后一关，听音选义、看词选义、句子填空三种题型
- **语音开口说**：
  - 🔊 点击喇叭朗读英文句子和单词（浏览器内置 TTS）
  - 🎤 可用语音回答问题（Web Speech API 语音识别，自动匹配最佳选项）
- **成长体系**：XP 经验与等级、1–3 星评价、生命值、每日连续打卡、6 枚成就徽章
- **自动存档**：进度保存在浏览器 localStorage，关掉页面也不会丢

## 🚀 运行方式

### 方式一：本地直接玩
双击打开 `index.html` 即可（推荐 Chrome / Edge 浏览器，语音识别功能仅这两款浏览器完整支持）。

### 方式二：GitHub Pages 在线玩
推送后在仓库 **Settings → Pages** 中选择 `main` 分支根目录即可获得在线网址，手机扫码也能玩。

## 🛠 技术栈

- 纯原生 HTML + CSS + JavaScript，**零依赖、零构建**
- Web Speech API：`SpeechSynthesis`（朗读）+ `SpeechRecognition`（语音识别，不支持时自动降级为点选）
- localStorage 本地存档
- 响应式布局，适配手机 / 平板 / 电脑
